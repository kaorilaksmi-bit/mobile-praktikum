# Proyek Pemrograman Mobile
## Deskripsi
Aplikasi latihan untuk kelas pemmob
## Pengembang
Kaori / akun GitHub: kaorilaksmi@gmail.com
## Status
Proyek awal perkuliahan.

## Tujuan
Menyediakan aplikasi layanan transportasi dan pengiriman untuk mempermudah mobilitas dan efisiensi waktu pengguna sehari-hari.

## Rencana Fitur
1. **GrabBike/GrabCar:** Layanan transportasi *ride-hailing* dengan pelacakan *real-time*.
2. **GrabFood:** Layanan pesan antar makanan.
3. **GrabExpress:** Layanan kurir pengiriman dokumen/barang instan.

## Cara Menjalankan
Pastikan Anda sudah berada di dalam folder proyek, lalu jalankan perintah berikut di terminal:

```bash
flutter pub get
flutter run
